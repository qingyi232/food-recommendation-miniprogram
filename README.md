# 基于微信小程序的校园周边美食推荐系统

## 项目简介

本系统是一个基于微信小程序的校园周边美食推荐平台，采用 **Spring Boot + 微信小程序 + MySQL** 技术栈开发。系统包含三个角色端：用户端、商家端、管理员端，重点突出**个性化推荐功能**和**数据可视化模块**。

## 技术栈

| 层面 | 技术 |
|------|------|
| 后端框架 | Spring Boot 2.7 |
| 开发语言 | Java 1.8 |
| 数据库 | MySQL 5.7+ |
| ORM框架 | MyBatis-Plus 3.5 |
| 前端 | 微信小程序原生开发 |
| 管理后台 | HTML + ECharts 可视化 |
| 认证方式 | JWT Token |
| 工具库 | Hutool、FastJSON |

## 系统功能模块

### 用户端（微信小程序）
- **注册/登录** - 支持账号密码登录和微信快捷登录
- **个人中心** - 个人信息管理
- **口味偏好设置** - 设置辣度/甜度/酸度/咸度偏好和喜欢的分类
- **在线下单** - 店铺内选菜加入购物车并提交订单
- **美食浏览** - 浏览所有店铺和菜品信息
- **分类筛选** - 按美食分类筛选店铺和菜品
- **个性化推荐** - 基于协同过滤+内容推荐的混合推荐算法
- **收藏店铺** - 收藏/取消收藏店铺
- **发布/查看评价** - 对店铺进行多维度评价（口味、服务、环境）
- **收藏/分享美食** - 收藏和分享菜品给好友

### 商家端（微信小程序）
- **注册/登录** - 商家账号注册与登录
- **个人中心** - 商家信息管理、数据统计概览
- **商户信息展示** - 展示商家基本信息
- **店铺信息维护** - 添加/编辑店铺信息
- **菜品管理** - 添加/编辑/上下架菜品
- **数据统计** - 订单数据、收入统计
- **订单查看** - 查看和处理订单

### 管理员端（Web后台）
- **商家管理** - 商家审核、状态管理
- **用户管理** - 用户查看、状态管理
- **违规商家处理** - 违规记录、警告/禁用处理
- **用户违规处理** - 用户违规记录与处理
- **评价管理** - 评价审核、违规标记、删除
- **分类管理** - 美食分类的增删改查
- **数据可视化** - 多维度数据图表展示（ECharts）

### 个性化推荐算法
- **协同过滤推荐** - 基于用户行为相似度的推荐
- **内容推荐** - 基于用户口味偏好的推荐
- **热门推荐** - 基于评分和销量的热门推荐
- **混合推荐** - 综合多种算法的混合推荐策略

## 快速开始

### 环境要求
- JDK 1.8+
- Maven 3.6+
- MySQL 5.7+
- 微信开发者工具

### 数据库初始化
1. 创建 MySQL 数据库并执行 `sql/init.sql` 脚本
2. 修改 `backend/src/main/resources/application.yml` 中的数据库连接信息

### 后端启动
```bash
cd backend
mvn spring-boot:run
```
后端启动后访问 `http://localhost:8080`

### 管理后台访问
浏览器访问 `http://localhost:8080/admin/index.html`
- 管理员账号：admin
- 管理员密码：admin123

### 小程序配置
1. 使用微信开发者工具打开 `miniprogram` 目录
2. 修改 `app.js` 中的 `baseUrl` 为后端实际地址
3. 如需微信登录，配置 `application.yml` 中的 `wechat.appid` 和 `wechat.secret`

## 数据库设计

系统包含14张数据表：
- `user` - 用户表
- `merchant` - 商家表
- `admin` - 管理员表
- `category` - 美食分类表
- `shop` - 店铺表
- `dish` - 菜品表
- `order_info` - 订单表
- `order_item` - 订单明细表
- `review` - 评价表
- `favorite_shop` - 收藏店铺表
- `favorite_food` - 收藏美食表
- `share_record` - 分享记录表
- `user_behavior` - 用户行为记录表（用于个性化推荐）
- `violation_record` - 违规记录表
