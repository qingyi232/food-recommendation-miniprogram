一、环境准备（需要安装的软件）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

请依次安装以下软件，所有软件均为免费：

1. JDK 17（Java开发工具包）
   下载地址：https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html
   选择 Windows x64 Installer 下载安装。
   安装完成后验证：打开命令提示符（cmd），输入：
       java -version
   看到 "java version 17.x.x" 即表示安装成功。

2. MySQL 8.0（数据库）
   下载地址：https://dev.mysql.com/downloads/installer/
   选择 mysql-installer-community 下载安装。
   安装时注意事项：
     - 安装类型选择 "Developer Default" 或 "Server only"
     - 设置 root 密码为：root（与项目配置一致）
     - 端口保持默认 3306
     - 勾选 "Configure MySQL Server as a Windows Service"（开机自启）
   安装完成后验证：打开命令提示符，输入：
       mysql -u root -p
   输入密码 root，能进入MySQL命令行即表示成功。

3. 微信开发者工具（小程序开发IDE）
   下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   选择 "稳定版 Windows 64" 下载安装。
   安装后用自己的微信扫码登录即可。

二、数据库初始化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤1：打开命令提示符（cmd），登录MySQL：
    mysql -u root -p
    （输入密码：root）

步骤2：执行SQL初始化脚本，复制粘贴以下命令：
    source 你的项目路径/sql/init.sql;

    例如项目放在 D:\campus-food 目录下，则输入：
    source D:/campus-food/sql/init.sql;

    注意：路径中使用正斜杠 / 而不是反斜杠 \

步骤3：验证数据库是否创建成功：
    show databases;
    （应该能看到 campus_food 数据库）

    use campus_food;
    show tables;
    （应该能看到 user、merchant、shop、dish 等多张表）

步骤4：输入 exit 退出MySQL命令行。

三、启动后端服务
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

本项目后端已内置Maven，无需额外安装Maven。

步骤1：打开命令提示符（cmd）

步骤2：进入后端目录：
    cd 你的项目路径\backend
    例如：cd D:\campus-food\backend

步骤3：设置Java环境变量并启动（二选一）：

  【方式A】如果JDK 17已配置到系统环境变量PATH中：
    mvn spring-boot:run
    或使用项目内置Maven：
    maven\apache-maven-3.9.6\bin\mvn.cmd spring-boot:run

  【方式B】如果未配置环境变量（推荐此方式，更稳妥）：
    set JAVA_HOME=C:\Program Files\Java\jdk-17
    maven\apache-maven-3.9.6\bin\mvn.cmd spring-boot:run

    注意：JAVA_HOME 路径根据你实际安装JDK的路径填写。

步骤4：等待启动，首次启动需要下载依赖，可能需要3-10分钟。
    看到类似以下信息表示启动成功：
    "Started CampusFoodApplication in x.xxx seconds"

步骤5：验证后端是否正常运行：
    打开浏览器，访问：http://localhost:8080/admin/index.html
    能看到管理员登录页面即表示后端运行成功。

【重要提示】
  - 后端启动后不要关闭命令提示符窗口，关闭则后端停止运行
  - 如果8080端口被占用，检查是否有其他程序占用了该端口
  - 如果MySQL密码不是 root，需修改配置文件：
    backend\src\main\resources\application.yml
    找到 password: root 改成你的MySQL密码

      例如：D:\campus-food

九、常见问题排查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1：后端启动报错 "Access denied for user 'root'"
A：MySQL密码与配置不一致。打开 backend\src\main\resources\application.yml，
   将 password: root 修改为你实际设置的MySQL密码。

Q2：后端启动报错 "Unknown database 'campus_food'"
A：数据库未初始化。请回到第二步执行SQL脚本。

Q3：后端启动报错 "Port 8080 already in use"
A：8080端口被其他程序占用。解决方法：
   - 关闭占用8080端口的程序，或
   - 修改 application.yml 中 server.port 为其他端口（如8081）

Q4：小程序页面显示空白/无数据
A：检查后端是否已启动（浏览器访问 http://localhost:8080 是否正常）。
   检查微信开发者工具"详情 → 本地设置"是否已勾选"不校验合法域名"。

Q5：首次启动后端非常慢
A：首次启动需要下载Maven依赖包（约100MB），取决于网络速度。
   如果下载过慢，可配置Maven国内镜像源：
   编辑 backend\maven\apache-maven-3.9.6\conf\settings.xml，
   在 <mirrors> 标签内添加：
   <mirror>
     <id>aliyun</id>
     <mirrorOf>central</mirrorOf>
     <url>https://maven.aliyun.com/repository/central</url>
   </mirror>

Q6：管理员后台页面样式不对/图标不显示
A：按 Ctrl+Shift+Delete 清除浏览器缓存后刷新页面。

Q7：小程序登录后无法查看数据
A：确认使用的是测试账号（user01/123456），且后端服务正在运行。
