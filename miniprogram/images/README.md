# 图片资源说明

## Tab栏图标（必需）
请将以下图标文件放入 `tab/` 目录下，尺寸建议 81x81 px：
- home.png / home-active.png - 首页图标
- category.png / category-active.png - 分类图标
- recommend.png / recommend-active.png - 推荐图标
- mine.png / mine-active.png - 我的图标

## 默认占位图（必需）
- default-shop.png - 店铺默认图片
- default-dish.png - 菜品默认图片
- default-avatar.png - 用户默认头像

## 轮播图
- banner1.png / banner2.png / banner3.png - 首页轮播图

## 分类图标
- category/ 目录下放置各分类图标
